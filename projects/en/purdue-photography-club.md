## About the Club

Purdue Photography Club brings together photographers in West Lafayette through photo walks, darkroom nights, critiques, socials, competitions, and member photo nights. Whether you shoot film, digital, or both, there is a place for you here.

Members can learn, share their work, borrow equipment, and use the club's darkroom and studio facilities according to their membership access.

## What We Build

This organization hosts the open-source projects and internal tools that support the club's website, Discord community, memberships, facilities, communications, and events.

| Project | What it powers |
| --- | --- |
| [Website](https://github.com/PurduePhotographyClub/purdue-photo-website) | Public pages, gallery, events, memberships, and member and officer tools |
| [Discord](https://github.com/PurduePhotographyClub/purdue-photo-discord) | Commands, verification, role sync, notifications, and staff workflows |
| [Wiki](https://github.com/PurduePhotographyClub/purdue-photo-wiki) | The club's documentation and photography knowledge base |
| [Email Worker](https://github.com/PurduePhotographyClub/purdue-photo-email-worker) | Purchase receipt processing and membership fulfillment |
| [Scheduler Worker](https://github.com/PurduePhotographyClub/purdue-photo-scheduler-worker) | Scheduled maintenance, reminders, and recurring club operations |

Most of the platform is written in TypeScript and runs on Astro, React, Cloudflare Workers, D1, R2, and Discord.

## Contributing

Found a bug or have an idea? Open an issue in the relevant repository. For a larger change, describe the proposal before opening a pull request so the implementation can stay aligned with the club's production systems.

Each project README includes its own development setup and verification commands.
